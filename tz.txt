# Техническое задание
## Разработка программы для анализа профиля пучка на Python

### Общее описание
Необходимо разработать программу на Python для анализа профиля пучка электронов, который выбивается лазером с поверхности фотокатода, разгоняется и направляется в один из двух YAG кристаллов. Светимость кристалла фиксируется одной из двух CCD камер, которые снимают изображение под воздействием внешнего триггерного сигнала. Программа должна получать изображение с камеры, обрабатывать его и отображать в различных представлениях, рассчитывать распределения для проекций точек изображения на оси координат, а также позволять сохранять данные на диск.

### Технические требования
- Язык программирования: Python
- Графический интерфейс: PyQt6
- Графики: PyQtGraph
- Работа с камерами: PyCapture2
- Работа с массивами: NumPy
- Сохранение данных: NumPy (.npy), поддержка чтения файлов формата .mat

### Архитектура программы
Программа должна иметь модульную структуру с четким разделением:
1. Модуль захвата данных (работа с камерами)
2. Модуль обработки и анализа данных (расчеты, преобразования)
3. Модуль представления (пользовательский интерфейс, визуализация)

### Пользовательский интерфейс
Программа должна содержать три вкладки:
1. **Вкладка основного изображения** - отображение и анализ текущих данных с камеры или из файла
2. **Вкладка фона (background)** - отображение и анализ фонового изображения
3. **Вкладка разницы** - отображение и анализ разницы между основным изображением и фоном

#### Для каждой вкладки:
- Центральное поле с тепловой картой матрицы значений светимости
- График нормального распределения проекций точек на ось X (внизу)
- График нормального распределения проекций точек на ось Y (слева)
- Информационный блок с координатами центроида и RMS по осям X и Y (в миллиметрах)

### Режимы работы программы
Программа должна работать в двух режимах:
1. **Режим работы с камерой**
2. **Режим чтения из файла**

Между режимами должно быть возможно переключение с сохранением состояния и результатов для каждого режима.

### Спецификация камер
Программа должна поддерживать две камеры:
1. **GUN_YAG1**
   - Разрешение: 1032 x 776 пикселей
   - Размер пикселя: 0.02840909 мм (по X и Y)
   - Название в системе Linux: fw1

2. **GUN_YAG2**
   - Разрешение: 1624 x 1224 пикселей
   - Размер пикселя: 0.01875468 мм (по X и Y)
   - Название в системе Linux: fw2

### Функциональные требования

#### Режим работы с камерой
1. **Выбор камеры:**
   - Выпадающий список для выбора камеры (GUN_YAG1, GUN_YAG2, не выбрана)
   - Кнопка "Начать работу с камерой"
   - Кнопка для завершения работы с камерой
   - Информационный блок с параметрами выбранной камеры

2. **Сбор фоновых данных (background):**
   - Редактируемое поле для указания количества кадров (по умолчанию 40)
   - Кнопка "Get background"
   - Кнопка "Stop" для остановки сбора фона
   - Предупреждение о необходимости закрыть затвор лазера
   - Отображение прогресса сбора кадров
   - Автоматическое осреднение собранных кадров

3. **Основной режим съемки:**
   - Кнопки "Start" и "Stop" для управления процессом съемки
   - Индикация текущего режима работы
   - Обработка триггерных сигналов от камеры
   - Кнопка "Export Data" для сохранения данных

#### Режим чтения из файла
1. **Загрузка файлов:**
   - Кнопка "Open" для выбора файлов
   - Поддержка форматов .npy и .mat
   - Автоматическое определение параметров камеры по размерности массива
   - Автоматическая загрузка парных файлов (основной и фоновый)

2. **Обработка загруженных данных:**
   - Отображение данных на соответствующих вкладках
   - Расчет и отображение проекций, центроидов и RMS

### Алгоритмы обработки данных

#### Преобразование данных с камеры
1. Преобразование данных формата Bayer в оттенки серого
2. Нормализация значений от 0 до 1
3. Преобразование в формат с плавающей точкой (double)

#### Расчет центроида
1. Создание сетки координат, центрированной относительно центра изображения
2. Вычисление сумм интенсивности по осям X и Y
3. Нормализация сумм относительно максимального значения
4. Расчет взвешенного среднего положения:
   ```
   центроид_x = сумма(координата_x * интенсивность_x) / сумма(интенсивность_x)
   центроид_y = сумма(координата_y * интенсивность_y) / сумма(интенсивность_y)
   ```

#### Расчет RMS
1. Использование найденных координат центроида
2. Вычисление взвешенного среднеквадратичного отклонения:
   ```
   rms_x = sqrt(сумма(интенсивность_x * (координата_x - центроид_x)²) / сумма(интенсивность_x))
   rms_y = sqrt(сумма(интенсивность_y * (координата_y - центроид_y)²) / сумма(интенсивность_y))
   ```

### Формат выходных данных
При экспорте программа должна создавать файл в формате NumPy (.npy), содержащий:
- Разрешение камеры (resolution)
- Размер пикселя (pixel_size)
- Дата и время сохранения (data)
- Исходная матрица значений светимости (raw)
- Матрица усредненного фона (background)
- Разница между исходной матрицей и фоном (difference)

### Обработка ошибок
- Вывод сообщений об ошибках при недоступности камеры
- Вывод сообщений при невозможности открыть файл
- Корректная обработка исключений при работе с камерой и файлами

### Дополнительные требования
1. Программа должна корректно масштабировать графики при изменении размера окна
2. Графики проекций должны всегда соответствовать размерам основного изображения
3. Программа должна иметь понятный пользовательский интерфейс
4. Программа должна правильно преобразовывать координаты из пикселей в миллиметры
5. Программа должна быть готова к подключению новых камер того же типа
