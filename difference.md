# Сравнение формул для отображения проекций данных в MATLAB и Python

## Основные формулы в MATLAB версии

MATLAB-версия использует функцию `AVG_STD.m` для вычисления проекций и их характеристик:

### 1. Создание координатной сетки
```matlab
mMdataSize = size(data);
[mX,mY] = meshgrid((-(mMdataSize(1,2)-1)/2):(mMdataSize(1,2)/2), (-(mMdataSize(1,1)-1)/2):(mMdataSize(1,1))/2);
xdata = mX(1,:);
ydata = mY(:,1);
```

### 2. Вычисление проекций на оси X и Y
```matlab
sx = sum(data);        // Сумма по столбцам для проекции X
data1 = data';
sy = sum(data1);       // Сумма по строкам для проекции Y
```

### 3. Нормализация проекций
```matlab
sxn = sx/max(sx);      // Нормализация относительно максимального значения
syn = sy/max(sy);
```

### 4. Вычисление взвешенного среднего (центроид)
```matlab
for i=1:length(xdata)
    avgx1 = avgx1 + xdata(i)*sxn(i);
    sumx = sumx + sxn(i);
end
averagex = avgx1/sumx;

for j=1:length(ydata)
    avgy1 = avgy1 + ydata(j)*syn(j);
    sumy = sumy + syn(j);
end
averagey = avgy1/sumy;
```

### 5. Вычисление взвешенного среднеквадратичного отклонения
```matlab
for i=1:length(xdata)
    stdx1 = stdx1 + sxn(i)*(xdata(i)-averagex)^2;
end
sigmax = real(sqrt(stdx1/sumx));

for i=1:length(ydata)
    stdy1 = stdy1 + syn(i)*(ydata(i)-averagey)^2;
end
sigmay = real(sqrt(stdy1/sumy));
```

## Основные формулы в Python версии

Python-версия использует класс `ImageAnalyzer` из модуля `analysis/image_analyzer.py`:

### 1. Вычисление проекций на оси X и Y
```python
x_proj = np.sum(processed_image, axis=0)  # Сумма по строкам (ось 0)
y_proj = np.sum(processed_image, axis=1)  # Сумма по столбцам (ось 1)
```

### 2. Нормализация проекций
```python
if np.max(x_proj) > 0:
    x_proj = x_proj / np.max(x_proj)
if np.max(y_proj) > 0:
    y_proj = y_proj / np.max(y_proj)
```

### 3. Вычисление центроида
```python
centroid_x_px = np.sum(np.arange(x_size) * x_proj) / x_sum
centroid_y_px = np.sum(np.arange(y_size) * y_proj) / y_sum
```

### 4. Вычисление среднеквадратичного отклонения (RMS)
```python
rms_x_px = np.sqrt(np.sum(x_proj * (np.arange(x_size) - centroid_x)**2) / x_sum)
rms_y_px = np.sqrt(np.sum(y_proj * (np.arange(y_size) - centroid_y)**2) / y_sum)
```

### 5. Аппроксимация гауссовым распределением (отключена в UI)
```python
def gaussian(x, a, mu, sigma):
    return a * np.exp(-(x - mu)**2 / (2 * sigma**2))
```

## Сходства двух реализаций

1. **Математические принципы**: Обе версии используют одинаковые математические принципы для вычисления проекций и их характеристик.
2. **Нормализация**: В обоих случаях проекции нормализуются относительно максимального значения.
3. **Центрированная система координат**: В обеих версиях используется система координат, центрированная относительно середины изображения.
4. **Взвешенные средние**: Оба кода используют интенсивность как вес при вычислении средних значений и отклонений.

## Различия двух реализаций

1. **Программная реализация**: 
   - MATLAB использует циклы для вычислений
   - Python использует векторизованные операции NumPy, что обеспечивает более высокую производительность

2. **Дополнительная функциональность**: 
   - Python-версия имеет функцию для аппроксимации профиля гауссовым распределением (хотя и отключена в UI)
   - В MATLAB-версии такой функциональности нет

3. **Архитектура кода**:
   - Python-версия использует объектно-ориентированный подход с четким разделением логики
   - MATLAB-версия использует процедурный подход

4. **Визуализация**:
   - В Python UI реализовано комплексное отображение с несколькими связанными графиками
   - В MATLAB более простая визуализация с отдельными графиками

## Заключение

Математические принципы и формулы, используемые в обеих версиях, идентичны, что обеспечивает одинаковые результаты анализа. Основные различия заключаются в программной реализации и архитектуре кода, где Python-версия предоставляет более современную, расширяемую и производительную структуру.

Python-версия также имеет потенциал для расширения функциональности (например, аппроксимация гауссовым распределением), что может быть полезно для более глубокого анализа профиля пучка в будущем.
