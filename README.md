# Beam Profile Analyzer

Программное обеспечение для анализа профиля электронного пучка, выбиваемого лазером с поверхности фотокатода.

## Описание

Программа получает изображение с CCD камеры, которая фиксирует светимость YAG кристалла под воздействием пучка электронов. Анализирует полученные данные, формирует тепловые карты и графики распределения профиля пучка, а также вычисляет важные параметры пучка (центроид, RMS).

### Основные возможности:

- Работа с камерами Flea2 FL2-20S4M IEEE-1394
- Получение и обработка изображений в реальном времени
- Сбор и вычитание фонового изображения
- Построение тепловых карт и графиков проекций интенсивности
- Вычисление центроида и RMS пучка
- Экспорт данных в различных форматах (NPY, CSV, PNG)
- Импорт ранее сохраненных данных и MAT-файлов

## Системные требования

- Python 3.6
- PyQt5
- NumPy
- Matplotlib
- OpenCV
- SciPy
- PyCapture2 (для работы с камерами)

## Установка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/Beam-Profile-Analyzer.git
   cd Beam-Profile-Analyzer
   ```

2. Создайте виртуальное окружение Python и активируйте его:
   ```
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   venv\Scripts\activate     # Для Windows
   ```

3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

4. Установите библиотеку PyCapture2 для работы с камерами (следуйте инструкциям производителя).

## Запуск программы

```
python -m src.main
```

## Использование

1. **Режим работы с камерой**:
   - Выберите камеру из выпадающего списка и нажмите "Launch the camera"
   - Перед съемкой соберите фон, нажав "Get background"
   - Начните съемку кнопкой "Start"
   - После завершения съемки нажмите "Stop"
   - Экспортируйте данные кнопкой "Export Data"

2. **Режим чтения файлов**:
   - Переключитесь в режим "Чтение файлов"
   - Нажмите "Открыть файл" и выберите файл в формате NPY или MAT
   - Просмотрите данные на всех трех вкладках

3. **Вкладки**:
   - **Основная съемка**: Управление камерой и просмотр текущего изображения
   - **Фон**: Просмотр фонового изображения и его параметров
   - **Разность**: Просмотр разницы между основным изображением и фоном
