# Анализатор профиля пучка

Программа для анализа профиля электронного пучка, испускаемого лазером из фотокатода и захваченного ПЗС-камерами.

## Описание

Анализатор профиля пучка позволяет получать и анализировать изображения электронного пучка с CCD-камер Flea2 (через библиотеку PyCapture2). Программа обеспечивает сбор и обработку фоновых изображений, вычитание фона, анализ профиля пучка (центроид, RMS), отображение результатов в виде тепловых карт и графиков проекций, а также сохранение данных.

## Основные возможности

- Обработка изображений с двух разных камер (GUN_YAG1 и GUN_YAG2)
- Сбор и вычитание фоновых изображений
- Анализ профиля пучка с расчетом центроида и RMS
- Визуализация данных в виде тепловых карт и графиков проекций
- Сохранение и загрузка данных в форматах NumPy (.npy) и MATLAB (.mat)

## Установка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/your-username/beam-profile-analyzer.git
   cd beam-profile-analyzer
   ```

2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

3. Для работы с камерами необходимо установить библиотеку PyCapture2 согласно инструкциям производителя.

## Запуск программы

```
python run.py
```

## Требования

- Python 3.8 или выше
- PyQt6
- PyQtGraph
- NumPy
- SciPy
- PyCapture2 (для работы с камерами Flea2)

## Использование

### Режим работы с камерой

1. Запустите программу
2. Выберите режим "Работа с камерой"
3. Выберите камеру из выпадающего списка (GUN_YAG1 или GUN_YAG2)
4. Нажмите "Подключить камеру"
5. Для сбора фонового изображения нажмите "Собрать фон"
6. Для начала захвата изображений нажмите "Захват"
7. Для сохранения данных нажмите "Сохранить данные"

### Режим чтения из файла

1. Запустите программу
2. Выберите режим "Чтение из файла"
3. Нажмите "Загрузить файл" и выберите файл с данными (.npy или .mat)
4. Программа автоматически попытается найти и загрузить соответствующий файл с фоновыми данными (с суффиксом "_bg")
5. Анализируйте загруженные данные на вкладках "Основные изображения", "Фоновые изображения" и "Разностные изображения"

## Примечание

Для работы с камерами Flea2 требуется установка библиотеки PyCapture2, которая не доступна через pip и должна быть установлена отдельно в соответствии с инструкциями производителя.
