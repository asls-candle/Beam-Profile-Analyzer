# Beam Profile Analyzer — Поток данных и алгоритмы обработки

---

## 1. Общее описание

Приложение захватывает кадры с FireWire-камеры (IEEE 1394, протокол IIDC, pydc1394),
вычитает предварительно собранный фон и рассчитывает характеристики пучка (центроид,
СКО размера пучка) по результирующему разностному изображению. Результаты можно
экспортировать в виде CSV/JSON-файлов или PNG-изображений.

---

## 3. ROI — область интереса

### 3.1 Как задаётся ROI

Пользователь рисует прямоугольник на тепловой карте перетаскиванием левой кнопкой мыши.
Координаты захватываются в **миллиметрах** (пространство данных осей графика). Затем
они переводятся в **пиксельные индексы**:

```
x_min = round( x0_mm / pixel_size_x  +  img_width  / 2 )
x_max = round( x1_mm / pixel_size_x  +  img_width  / 2 )
y_min = round( y0_mm / pixel_size_y  +  img_height / 2 )
y_max = round( y1_mm / pixel_size_y  +  img_height / 2 )
```

Начало координат — **центр изображения**. Положительные X — вправо, Y — вверх.
Результаты ограничиваются диапазоном `[0, img_width]` и `[0, img_height]`.

Пиксельная ROI `(x_min, y_min, x_max, y_max)` сохраняется в `ImageAnalyzer.roi`.

### 3.2 Как ROI применяется к изображению

```python
cropped = image[y_min:y_max, x_min:x_max]   # срез numpy-массива
```

Этот обрезанный подмассив используется как вход для **всех** последующих вычислений
(проекции, центроид, СКО).

### 3.3 Координатная сетка внутри ROI

После обрезки индексы пикселей внутри подмассива начинаются с 0:

```
i = 0, 1, …, (x_max − x_min − 1)   — индексы столбцов внутри ROI
j = 0, 1, …, (y_max − y_min − 1)   — индексы строк внутри ROI
```

Именно эти локальные индексы используются при вычислении проекций, центроида и СКО.
Результат центроида выражается относительно **центра полного (необрезанного) изображения**.

### 3.4 ROI при экспорте

При нажатии «Export Data» с активной ROI все массивы изображений (shot, background,
difference) физически обрезаются до границ ROI **перед** сохранением. Поле `resolution`
в метаданных обновляется соответственно.

```
┌─────────────────────────────────────────────────────────────────┐
│               Полное изображение  (H × W)                       │
│                                                                 │
│   ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐                             │
│   │                               │                             │
│   │        ROI-подмассив          │  ← используется для         │
│   │   image[y_min:y_max,          │    всего анализа            │
│   │          x_min:x_max]         │                             │
│   │                               │                             │
│   └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘                             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 4. Алгоритмы анализа

Все алгоритмы работают с **разностным** изображением (float64, ∈ [0,1]).
Если ROI активна, изображение сначала обрезается (см. §3.2).

---

### 4.1 Проекции

```
calculate_projections(image, pixel_size_x, pixel_size_y)
```

**Шаг 1 — Суммирование вдоль каждой оси (маргинальные распределения):**

```
P_x[i] = Σ_j  image[j, i]       (сумма по всем строкам для столбца i)
P_y[j] = Σ_i  image[j, i]       (сумма по всем столбцам для строки j)
```

**Шаг 2 — Нормировка на максимум:**

```
P_x[i] = P_x[i] / max(P_x)
P_y[j] = P_y[j] / max(P_y)
```

**Шаг 3 — Перевод индекса пикселя в миллиметры:**

```
x_coords[i] = i · pixel_size_x       (мм, начало — левый край ROI)
y_coords[j] = j · pixel_size_y       (мм, начало — верхний край ROI)
```

**Выход:** `(x_coords [мм], P_x [отн. ед.], y_coords [мм], P_y [отн. ед.])`

---

### 4.2 Центроид

```
calculate_centroid(image, pixel_size_x, pixel_size_y)
```

**Шаг 1 — Маргинальные проекции (без нормировки):**

```
P_x[i] = Σ_j  image[j, i]
P_y[j] = Σ_i  image[j, i]
```

**Шаг 2 — Взвешенное среднее положение (в пикселях, в пределах ROI):**

```
           Σ_i  i · P_x[i]                   Σ_j  j · P_y[j]
c_x_px = ─────────────────────    c_y_px = ─────────────────────
               Σ_i  P_x[i]                        Σ_j  P_y[j]
```

**Шаг 3 — Перевод в миллиметры с центрированием относительно центра изображения:**

```
centroid_x = ( c_x_px  −  W_roi / 2 ) · pixel_size_x   [мм]
centroid_y = ( c_y_px  −  H_roi / 2 ) · pixel_size_y   [мм]
```

где `W_roi`, `H_roi` — размеры (возможно обрезанного) изображения в пикселях.

> **Примечание:** Центроид отсчитывается от **геометрического центра
> ROI-подмассива**, затем выражается в мм.

**Выход:** `(centroid_x [мм], centroid_y [мм])`

---

### 4.3 СКО (RMS) размера пучка

```
calculate_rms(image, pixel_size_x, pixel_size_y)
```

**Шаг 1 — Маргинальные проекции и центроид (те же, что в §4.2).**

**Шаг 2 — Взвешенное стандартное отклонение (в пикселях):**

```
            ┌  Σ_i  P_x[i] · (i − c_x_px)²  ┐½
rms_x_px =  │ ──────────────────────────────  │
            └         Σ_i  P_x[i]             ┘

            ┌  Σ_j  P_y[j] · (j − c_y_px)²  ┐½
rms_y_px =  │ ──────────────────────────────  │
            └         Σ_j  P_y[j]             ┘
```

**Шаг 3 — Перевод в миллиметры:**

```
rms_x = rms_x_px · pixel_size_x   [мм]
rms_y = rms_y_px · pixel_size_y   [мм]
```

**Выход:** `(rms_x [мм], rms_y [мм])`

## 5. Размер пикселя

Размер пикселя (мм/пикс) определяется автоматически по разрешению сенсора:

| Разрешение сенсора | Размер пикселя (мм) |
|---|---|
| 1032 × 776  | 0.02840909 |
| 1624 × 1224 | 0.01875468 |
| прочие      | 0.01 (по умолчанию) |

Одни и те же значения `pixel_size_x` и `pixel_size_y` используются для всех
координатных преобразований в §4 и для осей на графиках проекций.

## 9. Примечания

* **Порядок байт:** Все используемые камеры — FireWire IIDC (Flea2 и аналоги).
  Они всегда передают данные в порядке **big-endian**. Декодер использует
  `dtype='>u2'` (big-endian, беззнаковое 16-битное) безусловно.

* **Нормировка фона:** Фоновое изображение нормируется с использованием
  *текущего кадра* в качестве референса. Это означает, что `background` и
  `current_frame` находятся на одной шкале интенсивности — их разность
  физически корректна.

* **Отрицательные значения:** Вычитание сырого фона из сырого кадра может
  давать отрицательные значения (шум, флуктуации тёмного тока). Они обрезаются
  до нуля перед нормировкой.

* **Центроид и СКО в мм:** Все пространственные характеристики вычисляются
  **сначала в пространстве пикселей**, затем умножаются на размер пикселя
  из таблицы. Промежуточная сетка в миллиметрах для интегрирования не строится.

* **Влияние ROI на центроид/СКО:** При активной ROI центроид отсчитывается
  относительно **геометрического центра подмассива ROI**, а не центра всего сенсора.

* **Медианный фильтр:** Код содержит функцию `apply_median_filter`, однако
  она **отключена** (закомментирована). Никакая пространственная фильтрация
  к данным не применяется.

* **Аппроксимация Гаусса:** Функция `fit_gaussian` присутствует в классе
  `ImageAnalyzer`, но **не вызывается** в текущем конвейере обработки и не
  влияет на отображаемые или экспортируемые значения.
